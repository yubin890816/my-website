## MODIFIED Requirements

### Requirement: 目标清单展示

GoalsPage（从 OverviewPage 抽取为独立页面）SHALL 展示当日学习目标清单，每项目标包含标题、科目标签、预计时长、完成状态。数据源仍为前端状态管理（本期不持久化到后端）。

- **GIVEN** 访客进入 GoalsPage
- **WHEN** 目标清单区域渲染完成
- **THEN** 出现当日目标列表
- **AND** 每项目标显示标题文本
- **AND** 每项目标显示科目标签（如"数学"/"英语"/"编程"）
- **AND** 每项目标显示预计时长（如"45 分钟"）
- **AND** 每项目标左侧显示可点击的勾选框

#### Scenario: 勾选切换完成状态

- **GIVEN** 目标清单已渲染，某项目标当前为未完成状态
- **WHEN** 访客点击该目标的勾选框
- **THEN** 勾选框变为已勾选样式（打勾 + 填充色）
- **AND** 目标标题添加删除线样式
- **AND** 整体不触发页面跳转

#### Scenario: 取消勾选

- **GIVEN** 某项目标当前为已完成状态
- **WHEN** 访客再次点击该目标的勾选框
- **THEN** 勾选框恢复未勾选样式
- **AND** 目标标题删除线移除

#### Scenario: 勾选触发学习日志写入

- **GIVEN** 用户勾选某项目标完成
- **WHEN** 勾选状态变为已完成
- **THEN** 前端调用 `POST /api/study-logs` 写入一条学习日志
- **AND** 日志含 `date`（今日）、`study_minutes`（目标预计时长）、`goals_completed`（1）
- **AND** 写入失败时不回滚 UI 状态（乐观更新）

#### Scenario: 目标清单为空

- **GIVEN** 当日无任何目标数据
- **WHEN** 目标清单区域渲染
- **THEN** 显示空状态占位（"今日暂无目标"文本）
- **AND** 进度汇总隐藏
- **AND** 不渲染任何目标项

### Requirement: 完成进度汇总

目标清单顶部 SHALL 显示完成进度，包含已完成数 / 总数 与百分比进度条。

- **GIVEN** 目标清单渲染
- **WHEN** 查看清单顶部
- **THEN** 显示 "今日进度：X/Y" 文本（X 为已完成数，Y 为总数）
- **AND** 显示水平进度条，填充比例等于 X/Y
- **AND** 进度条填充色为 indigo 系

#### Scenario: 进度实时更新

- **GIVEN** 目标清单已渲染，当前进度为 2/5
- **WHEN** 访客勾选第 3 项目标
- **THEN** 进度文本立即更新为 "3/5"
- **AND** 进度条填充比例立即更新为 60%
- **AND** 更新过程无延迟（同步响应）

#### Scenario: 全部完成的状态

- **GIVEN** 目标清单中所有目标均为已完成
- **WHEN** 查看进度汇总
- **THEN** 进度文本显示 "Y/Y"
- **AND** 进度条 100% 填充
- **AND** 进度条颜色变为绿色（表示达成）

#### Scenario: 清单为空时汇总隐藏

- **GIVEN** 当日无任何目标数据
- **WHEN** 目标清单区域渲染
- **THEN** 进度汇总区域不显示
- **AND** 不出现 "X/Y" 文本与进度条
